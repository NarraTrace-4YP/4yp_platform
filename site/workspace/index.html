Workspace

Everything the team works with. Windmill, MLflow and the database share one sign-in per person: your details are in ~/ACCOUNTS.txt on the server. Ask an admin if you don’t have one.

Tools

  • O1 app

    Start here. Explains Stage 1 and where it stands, shows the datasets and where their reviews came from, runs each pipeline with its progress, and lets you browse cases, sections and template matches.

    Public page
    Open in Windmill

  • Windmill

    Runs the pipeline scripts and keeps every run. The team’s code is in f/dhr; your own experiments go in u/<username>.

    Team sign-in windmill.{{env "DOMAIN"}}
    O1 pipelineRecent runs

  • MLflow

    Records every experiment run and LLM call: the settings it used, the commit that ran it and what it produced.

    Team sign-in mlflow.{{env "DOMAIN"}}

  • GitHub

    All the code and the server setup. Every change goes in through a pull request that passes the checks and has one approval.

    Public github.com/NarraTrace-4YP
    Pull requestsActions

  • Datasets

    Where the reviews come from. DHRC-100 holds 100 reviews checked by hand; DHRC-RAW holds all 702 gathered, as unchecked automated output.

    Team access huggingface.co/4YP
    DHRC-100DHRC-RAW

  • Database

    PostgreSQL, holding the reviews and everything built from them. It isn’t open to the internet: reach it from your laptop through an SSH tunnel.

    Team sign-in SSH tunnel, port 5432

Documentation

The guides live in the repository’s README, next to the code they describe, so a change to how something works and its instructions go in together.
