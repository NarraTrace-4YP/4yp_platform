Workspace

The tools behind NarraTrace: how reviews are prepared, processing runs are managed and experiments are compared.

Tools

  • O1 app

    The interface for corpus preparation. Browse reviews, inspect their section structure and compare suggested template matches. The app also shows each step's latest results and dataset coverage. It only reads results; pipelines are run in Windmill.

    Public page
    Open in Windmill

  • O2 app

    The interface for knowledge organisation. Browse each wiki built from the reviews: its settings and progress, the graph of linked pages, the knowledge graph of people, agencies and events, and the pages themselves. It only reads results; builds are run in Windmill.

    Public page
    Open in Windmill

  • Windmill

    Coordinates the processing pipeline, from importing reviews to preparing sections for analysis. Pipelines are only started here, behind the team login. Run histories help the team track progress and investigate failures.

    Pipeline orchestration windmill.{{env "DOMAIN"}}
    O1 pipelineO2 pipelineRecent runs

  • MLflow

    Tracks experiments and model calls, recording their settings, code versions and outputs so results can be reproduced and compared.

    Experiment tracking mlflow.{{env "DOMAIN"}}

  • GitHub

    Keeps the project’s code and configuration under version control. Pull requests, automated checks and peer review help the team develop the pipeline together.

    Public github.com/NarraTrace-4YP
    Pull requestsActions

  • Datasets

    The source collections used by the pipeline. DHRC-100 contains 100 manually checked reviews; DHRC-RAW contains 702 automated extractions, including the same 100 reviews.

    Source datasets huggingface.co/4YP
    DHRC-100DHRC-RAW

  • How the data is organised

    PostgreSQL stores the source reviews, reconstructed sections and processing results. Keeping these together allows each result to be traced back to the material it came from.

    Data storage PostgreSQL
